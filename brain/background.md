# Project background

**九州志（jiuzhou.world）** 是一部线上的中国方志。根上认《禹贡》的办法：以山川别九州。州是山川，是风土；方志是写法；城是写作单位。站点用静态网页承载文学性长文、地方史地、山水名胜、人文物产与读者供图入口。

总图见 [[anthology-spine]]。总脉见 [[root-pulse-mountains-rivers]]。层级见 [[anthology-one-city-one-volume]]。

## 它解决什么问题

九州志不是旅游攻略、点评社区、景区百科或公开相册，而是把一座城整理成可阅读、可浏览、可分享、可索引的数字方志。当前重点是：

- 让读者从九州总目进入浙江（今制轮廓），再进入杭州卷一，并可下行到下辖临安卷。
- 每一卷用自己的一条山川立读法：杭州从湖读起，临安从山读起、随水而下。
- 让多语言读者可以直接阅读完整正文：中文为底本，英文 / 日文 / 韩文是改写后的全文，而不是逐句对译。
- 让读者通过邮件贡献照片，把自己的地方影像记入对应卷。
- 古州是身份（杭州、临安属古扬州），不是选址配额；浙江可以继续写。

## 目标用户

- 对中国地方史地、山水、人文、旅行文化感兴趣的读者。
- 想分享某卷照片、但不需要社交社区功能的供图者。
- 需要可分享、可索引、多语言静态内容页的站点维护者与内容作者。

## 当前产品面

- 站点首页：九州铭文、缘起、顶层市卷（杭州）。
- 省页 /zhejiang：一句身份 + 诸市导航，无正文。
- 杭州卷：卷一，四章（山川、景、物、史）+ 下辖临安。读法与条目见 [[hangzhou-narrative-spine]]。
- 临安卷：/hangzhou/linan，四章 + 供图。旧 /linan/* 301 到此。
- 关于页：说明项目不是宣传册，而是线上地方志。
- 供图：总入口 `/contribute`；临安已单开；杭州 `/hangzhou/contribute` 收湖与城，正文落地时做页。见 [[photo-contribute]]。
- 多语言：中文默认无前缀；`/en`、`/ja`、`/ko` 为前缀语言。

## 非目标

- 不做账号、评论、公开相册、实时上传或审核后台。
- 不做实时地图、GIS、路线规划或 OTA 产品。
- 不做景区目录式铺开。
- 当前不以 CMS / 数据库驱动内容为主，优先保持静态站点、构建期渲染和边缘托管。
- 不把首页九州铭文做成可点的分卷进度图。

## 成功标准（当前阶段）

- 根上总脉在首页 / 省页 / 卷首读法上读得出来。
- 杭州卷一与临安下辖卷内容完整、互文不复读、页面可读。
- 四种语言 key 完整，正文按各语言自然改写。
- SEO 基础稳定：canonical、hreflang、sitemap、JSON-LD、OG 图可用。
- 供图入口清楚表达「按卷收稿、各卷标准不同」。
