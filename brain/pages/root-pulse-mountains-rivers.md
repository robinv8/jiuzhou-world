# 根上总脉：山川为纲

《禹贡》：「禹敷土，随山刊木，奠高山大川。」书序：「禹别九州。」州不是行政圈，是以山川为骨架划出来的。九州志认这条为根。总图见 [[anthology-spine]]。

- **地图**：九州 = 以山川划分的天下。州是山川，是风土。今日州名不在地图上，山川与风土还在。
- **方法**：方志。一座城一座城地走访、阅读、写作。不是百科，不是攻略。
- **单位**：城（市卷）。「一卷一城」指写作单位，不是行政对等。

## 层级是总脉的下行

- **根 / 首页**：九州铭文（冀兖青徐扬荆豫梁雍）说明这部书的名字从何而来。九个字是底色，不是进度条。
- **省**：今制轮廓，不是真正单位。只做导航，带一句古州身份（浙江 = 古扬州之南）。不做正文、不设读法。
- **市卷**：真正的单位。每一卷用自己的一条山川立读法。
- **下辖卷**：市卷装不下的山川才立。不进首页、不参与全站编号。不是区县配额。杭州名录见 [[hangzhou-subvolumes-roster]]。

## 古州是身份，不是配额

- 古州只落两处：**省页 kicker**（古扬州之南）+ **首页市卷卡小字**（古扬州之地，写在「浙江 · 杭州」之下）。
- 卷首 kicker 只写今制（浙江 · 杭州），不叠古州。
- 临安不加古扬州，归属从简，只标杭州。
- 古扬州很大。浙江可以继续写，不必因为杭州已占扬州就换州。
- 民乐扁都口可标古雍州，本轮暂缓，见 [[second-volume-candidate-minle-biandukou]]。
- 不把首页九铭做成可点的分卷总图。

## 卷内骨架

全国四章为 **山川 / 景 / 物 / 史**，见 [[chapter-skeleton]]。山川之卷写系统，景之卷写去处，两章不抢同一个名字。

## 后果

- 每卷的山川脊柱是总脉的分支，不是各卷自找的写法。
- 「不是景区百科」是这条总脉的推论：只写能立住这一城山川的去处。
- 杭州开篇写湖不再别扭：湖就是这一卷的山川。
