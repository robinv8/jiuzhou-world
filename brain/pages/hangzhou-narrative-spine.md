# 杭州叙事脉络：从湖读起，向城而行

杭州是卷一。湖就是这一卷的山川。总脉见 [[root-pulse-mountains-rivers]]，四章见 [[chapter-skeleton]]，开卷决定见 [[volume-hangzhou]]。总图见 [[anthology-spine]]。史地硬约束见 [[gazetteer-historical-accuracy]]。

## 脊柱

读法：从湖读起，向城而行。
章序：山川 → 景 → 物 → 史。
密度标尺：山川/物/史每则两段，接近临安天目、开竿；景之卷 essence 接近吴山、河桥。不写攻略，不铺景区目录。

史之卷收束：都城卸下，湖山还在。与临安「名字的流转」互文同向、内容不重复，见 [[vol1-narrative-spine]]。

## 山川（系统，不是去处）

1. **西湖：一面镜子。** 独占「西湖」。本是海湾潟湖，历代疏浚才保住——人工的是梳妆，不是从平地挖湖。岛与堤是看湖的角度。已达密度，只维持。
2. **环湖诸山：眉眼之间。** 山因湖而秀，湖因山而幽。最好的看山处在湖上。吴山只作为近市的性情带过，**不写看城**（看城归景之卷吴山）。
3. **茶山：山不高，高处是茶园。** 写地貌：坡地、云雾、沙土、慢的春天。狮峰、翁家山、满觉陇是山名。标题不叫龙井。一芽一叶、明前、采茶归物之卷，正文一句指向即可。
4. **水：湖的上下文。** 泉 → 湖 → 河 → 江，作为系统。不独占「运河」「钱塘江」为条目标题。过场写「下一章」不写「下一卷」。

## 景（去处，不与山川抢名）

1. **灵隐。** 核：山把寺藏住。飞来峰「从何处飞来」是传说；冷泉、理公塔、造像是真的。不写香火、素斋、门票攻略（票写在 note）。
2. **西溪。** 核：城边的湿地，不是园。芦、柿、船在林中。滤水也滤喧嚣。不列十景。
3. **运河。** 核：南端在杭州，河还在走。拱宸桥到塘栖。不是夜景游船。史的脐带写在「回到人间」；此则只写去处。
4. **钱塘江。** 核：潮是力。观潮胜地盐官在**海宁**，不在杭州城里；杭州江段可看、潮矮一些。吴越筑塘可带一句。
5. **吴山。** 核：西湖看山，吴山看城。城隍阁是 2000 年新起仿古楼，不是古塔。已达密度，只维持。

## 物

1. **龙井茶。** 独占「龙井」。写一芽一叶、明前、手上的尺寸。山的云雾地貌已在茶山，这里写人怎样取叶。
2. **丝绸。** 唐已有名，南宋以后才是江南织造重心。不把「丝绸之府」提前到吴越。软是手感，硬是工序。今天还在穿。
3. **工艺。** 伞、扇、剪三件还在用的东西。进玻璃柜才变成遗产。不写成三家品牌小传。
4. **杭帮菜。** 湖里的味道。来历一律「相传」。菜在巷子里，不在大酒店菜单。

## 史（一座城如何被做成都城，再卸下）

1. **良渚：更早的城。** 余杭低地：土垣、城壕、坝。玉是礼器不是风景。不是考古手册、不报申遗徽章。吴越、南宋是再做一次城。
2. **吴越定都。** 筑罗城、修海塘、疏西湖。钱镠是临安人，只一句，指向临安卷。不写射潮、保境、家训。
3. **南宋都城。** 1129 升府，1138 定都。行在近一百四十年。林升那句在这里。不写名字回家。
4. **回到人间。** 卸下都城。明清已是省治。运河作为事实织进，不以运河为条目标题。三处遗产是湖、河、更早的城三层，不是三枚徽章。

不写：婆留井、纳土归宋、钱氏家训、府名与县名——这些只在临安。
