# 卷一叙事脉络：水脉脊柱 + 故事化改写

卷一（临安）的问题是「分类法而非脉络、单调、没有故事」。定下的改法分两层：

## 脊柱：水脉

- 主线为「山 → 水 → 人间 → 名字」：水从天目山系下来，源（太湖源）→ 流（峡谷）→ 汇（青山湖）→ 居（河桥/村落），出山即成人间；人在山水间置物（山核桃/鸡血石/天目盏）；人从山水里走出，把「临安」送进史书。
- 景之卷按「从峰顶到市镇」的下行重排：清凉峰 → 天目山 → 大明山 → 太湖源 → 大峡谷 → 青山湖 → 指南村 → 河桥。
- 章序由 山→景→史→物 改为 **山→景→物→史**，让史之卷「名字回家了」收束全卷。
- 卷首总叙改为「读法」；每章末尾写过场，把读者交给下一章。

## 血肉：故事化

- 每条目给一个叙事核（人、时刻、场面），事实不新增，只把已有事实用故事写法讲出。
- 用户审美确认：**更文学**——叙事更慢、意象更密。
- 叙事核清单：婆留井（生）、钱王射潮（吴越）、钱俶北上的不战之别（纳土）、家训一句（家训）、林升的诗其实是讽刺（名字）、乾隆与大树王/禅源寺钟声（天目）、日本僧人背盏下山（天目盏）、开竿的清晨（山核桃）。

## 约束

- 中文是底本；en/ja/ko 为文学性适配而非直译（见既有提交约定）。
- 不改事实；传奇与史实要在文字里分清（「传说」「相传」）。
