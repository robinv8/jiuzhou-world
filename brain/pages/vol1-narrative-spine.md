# 临安叙事脉络：从山读起，随水而下

临安是杭州下辖卷，不编号。原为卷一；2026-08-22 起杭州为卷一。水脉是总脉「山川为纲」落在这一卷上的分支，见 [[root-pulse-mountains-rivers]]、[[anthology-one-city-one-volume]]。四章容器见 [[chapter-skeleton]]。与杭州卷的分家见 [[hangzhou-narrative-spine]]。史地硬约束见 [[gazetteer-historical-accuracy]]。不是景区百科见 [[not-a-scenic-encyclopedia]]。

## 脊柱

读法：从山读起，随水而下。
章序：山川 → 景 → 物 → 史。
密度标尺：山川/物/史每则两段，接近天目、开竿、名字的流转；景之卷 essence 接近河桥。不写攻略，不铺景区目录。

**天目是分水岭，不是一条河的上游。** 北坡入苕溪→太湖；西坡入昌化溪→钱塘江。景之卷沿水写五处，是阅读顺序，不是同一条水的上下游。

史之卷收束：府名被借，县名未走。与杭州「都城卸下，湖山还在」互文同向、内容不重复。

卷首总叙为「读法」。每章过场写「下一章」，不写「下一卷」。物之卷不是最后一章。

**山川与景不抢同一个名字。** 天目、大明、清凉只写在山川（山本身：大树、台地、屋脊、水的出发）。景之卷只沿水写五处：太湖源（源）→ 大峡谷（流）→ 青山湖（汇）→ 指南村（居）→ 河桥（市镇）。

## 山川（系统，不是去处）

1. **天目：大树的时间。** 核：树比庙老。大树王（千秋树）已枯，干还立着；活着的是柳杉群落。名字换了，林子还在。已达密度，只维持。不把「大树华盖闻九州」写成古人咏天目。生物圈、禅源寺可带，核仍是树。

2. **大明：云上高台。** 核：千米之上藏着一块平原。山把草甸藏在顶上。朱元璋屯兵用「相传」，不必尽信。不写滑雪、索道、A 级；不与清凉抢「最高」，不与天目抢树。

3. **清凉：浙西的屋脊。** 核：不被打扰的高度。梅花鹿是高度保护下来的生命，不是吉祥物。海拔说「浙西最高」即可，不把 1787.4、没有索道、凌晨头灯写成攻略。不与大明抢云海栈道。

4. **水：山的下文。** 核：天目是分水岭。水向北入太湖、向西入钱塘。太湖源作为地名只带一句，独占在景之卷。过场写「下一章」。不把两条水系写成一条河。

山川 intro 要点分水岭，不要只写「太湖水最初的来处」。

## 景（去处，不与山川抢名）

阅读顺序：太湖源 → 峡谷 → 青山湖 → 指南村 → 河桥。北三处太湖水系，谷与镇钱塘水系。season/note 可留实用一行，essence 不写攻略。

1. **太湖源。** 核：浩渺始于一线。源，不是谷。属太湖水系。不写老少咸宜、步道平缓。

2. **浙西大峡谷。** 核：绿是水的颜色，不是树的颜色。钱塘江的源流在深潭里。属钱塘水系。柘林瀑、剑门关可作地名带过，不列景点。不写徒步时长。

3. **青山湖。** 核：水库成湖。树从水里长出来。城区边上的静。属太湖水系。不写绿道骑行。

4. **指南村。** 核：人住在树的高度上。古树环村，秋色是人与树一起过的季节。属太湖水系。不写华东最美、摄影爱好者、民宿。去处在此，人的四季在物之卷。

5. **河桥。** 核：水慢下来，日子也慢下来。前店后河，下楼即是船埠。属钱塘水系。已达密度，只维持。不写免费开放。

## 物

1. **山核桃：白露开竿。** 核：开竿。一年的指望挂在最高的枝头。已达密度，只维持。不写「中国山核桃之乡」当徽章，不写营养与购买。

2. **昌化鸡血石。** 核：石上朱砂。山里挖出的一寸山河，放到案头。印石三宝一句带过。不写收藏行情。石头会尽，山河不会。

3. **天目盏。** 核：一只盏的名字成了一类器物的名字。日语「天目」由此而来。曜变是建窑，不是本地烧出。本地是另一路黑釉，正在重新燃起。已近密度，维持此分寸。

4. **村落：山里的人。** 核：四季的秩序还在。物最终是人的物。不写村名录，不开湍口温泉。指南村、河桥的去处已在景，这里只写人怎样过四季。

过场：下一章读史。不写「最后一卷」。

## 史（一个人、一个名字被都城借走）

1. **婆留井。** 核：命是婆留住的。那口井还在临安城里。红光、井边是传说。不展开贩盐从军演义。

2. **吴越保境。** 核：从临安带走的那件事是保境安民。射潮是传说。定都杭州、筑城疏湖只一句，指向杭州卷。相对安稳，不是没有兵戈；不写「几十年不闻兵戈」。

3. **纳土归宋。** 核：一国之地，未经一战。遵祖父遗训可写。978 年北汉仍在，不写完成统一。

4. **《钱氏家训》。** 核：遗训传家，比王朝长寿。通行本是后裔整理，句子不直接算钱镠原话。不把当代名人列成族谱成就展。钱王陵可带，不写成园。

5. **名字的流转。** 核：府名被借，县名未走。县名西晋太康元年（280）即有；南宋借的是府名。2017 设区是建制变化，不是回家。已达密度，只维持。不写林升、都城日常、临安府三百年。

不写：西湖、龙井、良渚、南宋都城——这些只在杭州。
