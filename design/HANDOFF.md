## 一、通则

### 两层结构（2026-10-14 起去掉扉页）

每个卷页自上而下：

1. **护封**：线上风格。通栏古画或版画 + 渐变 + 顶栏导航，标题和副标题用站点文案。首页护封是深色压暗、浅色字；浙江、杭州、临安是纸色淡化、墨色字，副标题衬签条。
2. **书芯**：书版式，不往线上风格靠。顺序：读法 → 舆图 → 目录 → 结语 → 牌记。

**扉页已删除**（首页、杭州卷、临安卷都删）：它和护封重复了书名。扉页上独有的「所属 + 刊行年 + 方印」并进护封，做成**落款**（见各节）。站点上已实现的扉页组件和相关文案键请一并删掉，`TitlePage` 若无他用也删除。

省页（浙江）本来就没有扉页；首页是总目，结构另见下。

### 只列已开

首页「卷」只放杭州卷，「省」只放浙江；省页「诸市」只放杭州和其下已开的临安。筹备中的卷、未开的省、未开的区县一律不出现，也不要做灰色占位。下辖卷（临安）不上首页。

### 字与色

- 字体全部是 `Noto Serif SC`（站点 `index.css` 已有的衬线栈即可）。竖排文字设计稿里是逐字换行，实现用 `writing-mode: vertical-rl`。
- 共用色：

| 用途 | 值 |
| --- | --- |
| 墨（正文主色） | `#1F2A26` |
| 朱（标签、朱批、印） | `#B03A2E` |
| 印内字 | `#F7F1E3` |
| 首页护封浅色字 | `#F7F5EE`（副文案按 E6/CC/99 透明度递减） |
| 纸色护封（浙江、杭州、临安）的字 | `#1F2A26`，透明度规则同上 |
| 牌记底 / 牌记字 | `#1F2A26` / `#E9E4D6`（次行 B3、三行 80 透明度） |

- 页面底色：首页 `#F3EEE2`，浙江 `#F1ECE0`，杭州 `#F3EEE2`（目录段 `#ECE5D2`），临安见第五节。
- 次级文字：首页、浙江 `#4A514B`；杭州书芯 `#3D4842`。

### 图注（必须实现）

- 这四页**只用老图**：公版古画、方志版画、古地图。不用 AI 重绘图，也不用现代照片。章节内页另有规则，见第六节。
- 每张图都写图注：朝代、作者或刊本、图名、藏处。文案见各节。
- 样式：小字（护封 12px，卡片内 11px），字距 2；首页护封（深底）用 `#F7F5EE99`，其余纸色护封与纸面上用 `#1F2A2699` / `#1F2A2680`。
